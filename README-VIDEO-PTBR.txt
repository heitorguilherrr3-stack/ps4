PS4 UI ORIGINAL + MEDIA PLAYER LOCAL

Como usar:
1. Extraia o ZIP inteiro.
2. Abra index.html em um navegador moderno (Chrome/Edge).
3. Aguarde a tela inicial; pressione Espaço/Enter para entrar, se necessário.
4. Selecione o cartão "Meu vídeo MP4" e escolha um vídeo da galeria/arquivos do celular.
5. Use os controles normais do player para pausar/avançar e "Controles" para esconder/mostrar a sobreposição visual do DualShock.

Observações:
- O projeto original e seus assets CSS/JS/imagens/fontes foram mantidos.
- Os jogos pré-configurados foram removidos do carrossel e substituídos pelo cartão de vídeo.
- O vídeo é aberto localmente no navegador; não é enviado para nenhum servidor.
- O controle virtual é uma sobreposição visual e não controla um jogo real: o conteúdo reproduzido é um vídeo.
- Em alguns navegadores móveis, abrir arquivos locais pode ter limitações; extraia o ZIP e abra o index.html, em vez de abrir o HTML dentro do visualizador de ZIP.
